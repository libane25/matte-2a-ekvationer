# Matte 2a Ekvationer

Practice app for the equations chapter of the Swedish high-school course Matematik 2a. It has 200 original questions, each with four choices and a worked answer.

Topics:

- Linjära ekvationer och formler
- Kvadrerings- och konjugatregeln
- Faktorisering
- Enkla andragradsekvationer
- Nollproduktmetoden
- Kvadratkomplettering
- pq-formeln
- Diskriminant och antal rötter
- Andragradsfunktioner
- Substitutionsmetoden
- Additionsmetoden
- Grafisk lösning och antal lösningar
- Potensekvationer
- Exponentialekvationer
- Tillämpningar

The app includes a short formula sheet. A round is ten new questions, a mixed set of ten, the questions you got wrong, or one topic at a time. The answer is shown after each question. Progress stays in the browser.

Open `index.html` in a browser. No build step.

Version 1.0.
